# NNNN. Title of the decision

Copy this file as `NNNN-short-title.md`, numbered after the last ADR. One decision per file.
Edit an ADR only to change its status; a new decision that replaces it is a new ADR.

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD
- Change: openspec change that introduced it, if any

## Context
What forces the decision. Facts, not opinions.

## Decision
What was decided, in one or two sentences.

## Alternatives considered
- Alternative: why it was rejected.

## Consequences
What becomes easier, what becomes harder, and what must now be done.
